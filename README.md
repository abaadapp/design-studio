# Abaad Design Studio

A shared design workspace for building and evolving Abaad's visual language and AI-assisted creative production.

## Goal

Create a consistent, high-quality design system that enables AI design agents to produce Abaad-branded social media posters and marketing creatives quickly, while preserving a recognizable Abaad identity.

## Working principle

This repository will grow gradually through real design experiments, approved references, and documented feedback. We will avoid over-defining the system before testing it.

## Status

**Phase 1 — Foundation**

The studio is being built step by step. Brand rules, references, assets, templates, and agent instructions will be added only as they are reviewed and approved.
